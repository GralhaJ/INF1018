Questão 3
Para obtermos nos bits menos significativos apenas o valor indicado pelo
parâmetro da função fazemos o shift:
word >> (8 * bytenum)
Para "limparmos" o restante dos bytes fazemos a máscara:
& (0xFF)
No final, atribuindo isso a uma nova variável de retornando temos:
int byte = (word >> (8 * bytenum)) & 0xFF;
Agora para verificar o sinal e estender essa informação para os bits
basta fazer um if (byte >> 7 == 1) então fazemos byte = byte | 0xFFFFFF00
Isso fara que caso o bit mais significativo (que indica o sinal) for 1
ele vai repetir o 1 em todos os outros bits para mantermos o sinal de negativo
Caso contrário ele mantém os 0, que indica sinal positivo.

Questão 4
Ao rodar o primeiro código temos:
x=-1, y=2
x é menor do que y? sim
Nesse caso as duas variáveis são do mesmo tipo (signed int), então
ocorre a comparação lógica -1<2 que retorna True
Ao rodar o segundo temos:
x=-1, y=2
x é menor do que y? nao
Nesse caso, como as duas variáveis são unsigned int, o valor de x é :
4.294.967.295 (2³² - 1), o maior valor que um unsigned int pode assumir
Porém na hora da impressão, por não usarmos %u, a interpretação é de que
ele é um signed int, logo fica -1.
Rodando com %u:
x=4294967295, y=2
x é menor do que y? nao
Rodando o programa 3, temos:
x=-1, y=2
x é menor do que y? nao
Quando comparamos variáveis de tipos diferentes, elas são convertidas
para o mesmo tipo, nesse caso foram convertidas para o tipo unsigned int
logo a comparação foi 4294967295 < 2?

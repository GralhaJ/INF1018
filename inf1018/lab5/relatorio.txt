O "buraco" é o padding de alinhamento que é inserido pelo
próprio copilador:
Um int (4 bytes) precisa estar em um endereço múltiplo de 4,
enquanto um short (2 bytes) precisa estar em um endereço múltiplo
de 2, para que c fique alinhado corretamente o copilador insere
2 bytes de padding, empurrando c para o offset 8, que é múltiplo de 4.

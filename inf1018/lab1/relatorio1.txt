tem como saída printf ("uso do programa: %s <valor float>\n", argv[0]);
E retorna 0, encerrando o programa.

Rodando:
gcc -Wall -o ex4 dump.c ex4.c
./ex4
Obtemos:
valor de c1: 1 -> na memória: 1 
valor de c2: 49 -> na memória: 49 
valor de i: 1 -> na memória: 1 0 0 0 
valor de v: 1 -> na memória: 49 0 

A função dump imprime cada byte da representação em memória de uma variável.
O ponteiro p é convertido em um unsigned char *, que ocupa exatamente um byte
e assim é usado para apontar para cada byte de uma variável.
Já a variável inteira n, usada em while(--n), serve para rodar n vezes o laço,
imprimindo o valor de cada byte.

O tamanho ocupado vai depender do tipo de variável.
variavéis tipo char ocupam 1 byte, variáveis tipo int ocupam 4 bytes.
Outra coisa que podemos notar é que armazer 1 e '1' são coisas diferentes.
'1' armazena o o byte de valor 49, número correspondendo na tabela ASCII para o caractere '1'.

Os bytes são apresentados da esquerda para a direita.
